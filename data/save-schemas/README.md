# Save schema database

These JSON packs describe save layouts for the runtime schema interpreter. Loading a changed pack does not require an application rebuild.

`schema-v1.schema.json` defines the authoring format for JSON-aware editors. Runtime checks additionally enforce storage bounds, nonconflicting writes, and work limits.

| Pack | Game ID | Coverage |
| --- | --- | --- |
| `super-mario-world.json` | `super-mario-world-schema` | All 233 File 1 fields, its checksum and backup, and fresh initialization |

The Super Mario World pack preserves Files 2 and 3. It requires a valid File 1 and an identical backup. The native handler retains broader file selection and recovery support. Tests compare every exposed field and generated bytes against that handler.

The layout and initialization follow [SMWDisX `rammap.asm`](https://github.com/IsoFrieze/SMWDisX/blob/30643c7595a7d097d731de69476f8059c7cf98c3/rammap.asm), [`bank_00.asm`](https://github.com/IsoFrieze/SMWDisX/blob/30643c7595a7d097d731de69476f8059c7cf98c3/bank_00.asm), and [`bank_04.asm`](https://github.com/IsoFrieze/SMWDisX/blob/30643c7595a7d097d731de69476f8059c7cf98c3/bank_04.asm). The last source defines the event bit order.
