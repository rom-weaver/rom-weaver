# Save schema sources

The `builtin_*` modules define the full game profiles. The catalog includes layouts adapted from [Game Tools Collection](https://github.com/RyudoSynbios/game-tools-collection/tree/fd8ca0beba05723fcfdb5af83c453ba9bea1221a), revision `fd8ca0beba05723fcfdb5af83c453ba9bea1221a`.

Game Tools Collection is copyright 2024 RyudoSynbios and uses the [MIT License](LICENSE-GAME-TOOLS-COLLECTION). The build includes this attribution in the CLI and browser notices.

F-Zero, Game & Watch Gallery 3, and Kirby's Adventure use revision `75ce8f848b628f202c50daa75d95dda58eb1f3a5` of the same source. Their module comments link the layouts and write rules.

ActRaiser, the two Capcom GBA EEPROM games, Chrono Trigger, Donkey Kong Land, the newer F-Zero games, Final Fantasy VI, Lylat Wars, Mario Kart 64, Mission: Impossible, Mystic Quest Legend, Pokémon Trading Card Game, Super Punch-Out!!, Wario Land 3, and the two Zelda Oracle games use revision [`8fb075e7c130da9e72c3c46ec8efa447a252ad88`](https://github.com/RyudoSynbios/game-tools-collection/tree/8fb075e7c130da9e72c3c46ec8efa447a252ad88). Diddy Kong Racing uses editor offsets from that revision and checksum rules from [DavidSM64/Diddy-Kong-Racing](https://github.com/DavidSM64/Diddy-Kong-Racing/blob/1339ad6304118207b342fe8669c500efb91969df/src/save_data.c). The Chrono Trigger slot checksum follows the game's own routine in [dscotton/ct_disassembly](https://github.com/dscotton/ct_disassembly/blob/eeae27acdb6565e96d1d796a3d60792c250c0aa1/bank_FF.asm#L1301-L1322), which chains the carry of each add into the next and drops the last one. Their module comments link the exact source directories.

ActRaiser, Chrono Trigger, Donkey Kong Country, Donkey Kong Country 2: Diddy's Kong Quest, Final Fantasy VI, Mystic Quest Legend, and Super Punch-Out!! also use revision [`15d71340c3f1717745139c2e0774510cd37dfbdd`](https://github.com/RyudoSynbios/game-tools-collection/tree/15d71340c3f1717745139c2e0774510cd37dfbdd) for their added fields and write rules; Chrono Trigger keeps its original slot checksum rule (the later upstream checksum change is not applied). The two Donkey Kong Country modules' original counter layouts come from revision `fd8ca0beba05723fcfdb5af83c453ba9bea1221a`. Their module comments link both directories.

Sonic 3, Shining Force, and Soleil also use Game Tools Collection revision [`8fb075e7c130da9e72c3c46ec8efa447a252ad88`](https://github.com/RyudoSynbios/game-tools-collection/tree/8fb075e7c130da9e72c3c46ec8efa447a252ad88). Sonic 3 checksum and block rules follow [jcfields/sonic3-save-editor](https://gitlab.com/jcfields/sonic3-save-editor/-/blob/8b740b670ff8e46f7c35ff8fac98169efccfe3b9/save%20format.md).

All profiles in these modules require explicit selection and a game-made template. Their definitions expose only the fields whose write and integrity rules are implemented. Omitted game data is not editable.

The Castlevania GBA, 1080° Snowboarding, Wario Land II, Yoshi's Story, and Link's Awakening modules also use revision `75ce8f848b628f202c50daa75d95dda58eb1f3a5`. Their module comments and the [source catalog](../../../../../../data/save-schemas/README.md) identify the layouts and write rules.

The Game Boy and Game Boy Color deepenings (Donkey Kong Land, Game & Watch Gallery 3, Pokémon Trading Card Game, the two Zelda Oracle games, Wario Land II, and Wario Land 3) and the F-Zero: Maximum Velocity deepening add editable fields from revision [`15d71340c3f1717745139c2e0774510cd37dfbdd`](https://github.com/RyudoSynbios/game-tools-collection/tree/15d71340c3f1717745139c2e0774510cd37dfbdd). Their upstream templates are unchanged since the earlier revisions, so the new fields reuse the layouts those revisions describe; each module comment links both revisions. The Oracle of Seasons module also corrects the health, heart piece, and rupee offsets, which previously used the Oracle of Ages positions.

The additional handheld, Nintendo 64, PlayStation, and PC Engine definitions use Game Tools Collection revision [`6f5d8064050eec83eb4f2a910743c121a70655c9`](https://github.com/RyudoSynbios/game-tools-collection/tree/6f5d8064050eec83eb4f2a910743c121a70655c9). Their module comments pin the field layouts and write rules. The [source catalog](../../../../../../data/save-schemas/README.md#additional-save-editors) lists accepted variants and exact editing scope, including supplementary Ocarina of Time and Final Fantasy VIII integrity sources.

The Diddy Kong Racing, F-Zero X, Lylat Wars, Mario Kart 64, Mario Party, Mario Party 2, and Mission: Impossible modules also expose the later fields of their templates at Game Tools Collection revision [`15d71340c3f1717745139c2e0774510cd37dfbdd`](https://github.com/RyudoSynbios/game-tools-collection/tree/15d71340c3f1717745139c2e0774510cd37dfbdd). Those templates are identical at that revision and at the revisions named above, so the earlier layout and checksum links remain valid. Each module comment links the exact directory.
